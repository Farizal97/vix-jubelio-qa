# Web Automation Testing - Sauce Demo (Alternative Assignment)

Proyek otomatisasi ini dibuat menggunakan **Selenium WebDriver (JavaScript/Node.js)** untuk menguji fitur *Login Flow* dan *Inventory Flow*.

> **Catatan Penting:** Karena masa trial 3 hari pada platform Jubelio telah habis, pengujian dialihkan ke website simulasi e-commerce standar industri, yaitu **Sauce Demo**, dengan kriteria dan alur pengujian yang setara.

## 🚀 Cara Menjalankan di Lokal

1. **Clone Repositori ini:**
   ```bash
   git clone https://github.com
   ```
2. **Masuk ke folder direktori:**
   ```bash
   cd nama-repo
   ```
3. **Instal library dependencies (Selenium):**
   ```bash
   npm install
   ```
4. **Jalankan skrip otomatisasi:**
   ```bash
   node automation.js
   ```
